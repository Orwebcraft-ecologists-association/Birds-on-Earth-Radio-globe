Quick Start Guide

  1. Launch the application using the button above
  2. Search for a radio station (try "BBC" or "NPR")
  3. Click a station to start playing
  4. Star it to add to favorites
  5. Check Detections tab to see your search history
  6. Open About modal and click the gear icon for Admin Mode
  7. Submit a station to test the approval workflow
